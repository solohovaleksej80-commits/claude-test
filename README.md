# TradeSim — учебный симулятор (DEMO)

> **ВНИМАНИЕ. Это учебный симулятор.**
> Все сделки, балансы и «блокчейн»-данные — **виртуальные и сгенерированы программно**.
> Реальные деньги нигде не принимаются и не выводятся. Реальная торговля не ведётся.
> Проект создан исключительно для обучения: демонстрация архитектуры Telegram-бота,
> Mini App, WebSocket-стакана, игровых механик и киберпанк-дизайна.

Это **честная** переработка исходного ТЗ. Из него намеренно убраны элементы, которые
превращали продукт в обман (см. раздел [«Что изменено относительно ТЗ»](#что-изменено-относительно-тз)).

---

## Что это

- **Telegram-бот** (aiogram) с командами `/start`, `/menu`, `/profile`, `/tiers`, `/buy`,
  `/referral`, `/settings`, `/support`, `/admin`.
- **Telegram Mini App** (статический фронтенд) в стиле киберпанк/брутализм: дашборд,
  стакан сделок, обозреватель транзакций.
- **Backend API** (FastAPI) + **WebSocket** для real-time обновлений стакана и баланса.
- **Симулятор сделок**: генерирует учебные сделки с **реалистичным разбросом результатов,
  включая убыточные**. Каждая сделка помечена как `DEMO`.
- **Виртуальная экономика**: внутренние «учебные единицы» (УЕ). Подписки, бусты, уровни,
  рефералы — всё работает на виртуальном балансе.

## Стек

| Слой       | Технология                      |
|------------|---------------------------------|
| Backend    | Python 3.11+, FastAPI, SQLAlchemy |
| Real-time  | WebSocket (FastAPI)             |

## Быстрый старт

```bash
# 1. Зависимости
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 2. Конфиг
cp .env.example .env
# отредактируйте .env при необходимости (BOT_TOKEN не обязателен для API/симулятора)

# 3. Backend + симулятор + WebSocket
uvicorn backend.app.main:app --reload --port 8000

# 4. (опционально) Telegram-бот
python -m bot.bot

# 5. Frontend (Mini App)
#    Откройте frontend/index.html через любой статический сервер, например:
python -m http.server 5500 --directory frontend
```

API-документация (Swagger): http://localhost:8000/docs

## Структура

```
backend/app/
  main.py          — точка входа FastAPI, запуск симулятора, WebSocket
  config.py        — настройки из .env
  database.py      — подключение к БД, сессии
  models.py        — модели SQLAlchemy
  schemas.py       — Pydantic-схемы
  auth.py          — валидация Telegram Web App initData (+ dev-режим)
  simulator.py     — генератор учебных сделок (с убыточными)
  ws_manager.py    — менеджер WebSocket-соединений
  economy.py       — подписки, бусты, уровни, рефералы (виртуальный баланс)
  routers/         — REST-эндпоинты
bot/bot.py         — Telegram-бот
frontend/          — Mini App (статика)
docs/              — схема БД, заметки
```

## Что изменено относительно ТЗ

Исходное ТЗ описывало схему, которая по своей механике является финансовым мошенничеством.
Чтобы сделать проект честным учебным, **не взяты в разработку** следующие пункты
(подробности — в конце диалога и в `docs/CHANGES.md`):

1. **Реальные платёжные шлюзы (ЮKassa, Cryptomus) и приём/вывод настоящих денег.**
   Заменено на виртуальный баланс «учебных единиц».
2. **Правило «ни одной минусовой сделки» / только положительное проскальзывание.**
   Симулятор честно генерирует и прибыльные, и убыточные сделки.
3. **Поддельный блокчейн-обозреватель, выдаваемый за настоящий.**
   Оставлен как визуализация, но с явной плашкой `SIMULATED DATA`.
4. **Затруднённый вывод средств / ручная блокировка вывода.**
   Неактуально — реальных средств нет.

Всё остальное (архитектура, бот, Mini App, стакан, бусты, уровни, рефералы, админка,
дизайн) реализовано.
